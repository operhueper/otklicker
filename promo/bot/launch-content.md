# Welcome-пакет для @otklicker_bot

Дата сборки: 2026-05-01.

Все тексты в голосе бренда (см. CLAUDE.md, PRODUCT_FACTS.md §9). Без em-dash, без штампов «уникальный/инновационный», конкретные цифры, короткие предложения, от лица команды.

---

## 1. Welcome-баннер (картинка)

- Файл: экспорт из `brandbook.pen`, nodeId `93hwV` (фрейм «Welcome Banner — bot v1»).
- Размер: 1280×640 px (стандарт превью описания TG-бота, безопасно масштабируется в чатлисте).
- Формат: PNG, 2x scale при экспорте.
- Что в кадре: фирменный градиент (FBBF24 → F97316 → EF4444 → DB2777, 135°), слева заголовок «Хватит писать сопроводительные руками» + логотип откликера и пилюля `@otklicker_bot · t.me/otklicker`, справа 4 кремовые карточки с фичами (резюме за 7 минут, тиндер вакансий, ответы HR в TG, сопроводительное под каждую).
- Куда заливать: `BotFather → /mybots → @otklicker_bot → Edit Bot → Edit Description Picture`.

Если на этапе ревью захотим вертикальную версию (для постов в @otklicker и сторис) — пересобираем тем же градиентом, шрифт Inter 800/500.

## 2. Welcome-сообщение (после /start)

Идёт в чат вместе с картинкой выше и кнопками главного меню.

```
Привет. Это откликер.

Если уже отправил 50 откликов и в ответ тишина, ты по адресу. Мы делаем три вещи, которые забирают часы каждый день:

1. Резюме за 7 минут. Голосом или текстом. Бот сам разложит опыт по полочкам и подскажет, где не хватает цифр.
2. Тиндер вакансий с HH. Свежие карточки прилетают в этот чат. Не нужно открывать 30 вкладок и заново выставлять фильтры.
3. Сопроводительное под каждую вакансию. Не шаблон, а письмо из вашего профиля и текста объявления. Три стиля на выбор.

Когда HR пишет в личку HH, бот предлагает ответ прямо здесь. Подтверждаете в одну кнопку.

Бесплатно: 1 резюме, 5 откликов, 10 карточек в день. Дальше пакет на 3 недели за 790 ₽.

Жмите «Старт» и поехали. Или загляните в канал @otklicker — там обновления продукта и истории пользователей.
```

Кнопки:
- 🚀 Старт (главное меню)
- 📺 Канал @otklicker (URL t.me/otklicker)
- ℹ️ Что внутри (FAQ-сообщение)

Длина: 720 символов, в один экран без скролла на iPhone.

## 5. Сборка для BotFather (порядок действий)

1. `BotFather → /setname` — `откликер` (если ещё не выставлено).
2. `BotFather → /setdescription` → вставить текст из §4.
3. `BotFather → /setabouttext` → вставить текст из §3.
4. `BotFather → /setdescriptionphoto` → загрузить экспорт `93hwV` 1280×640.
5. `BotFather → /setuserpic` → круглый аватар 512×512 из брендбука (раздел «Аватар бота», см. фрейм `C6S9Y` в `brandbook.pen`).
6. В коде бота на /start отдавать сообщение из §2 с кнопками и тем же баннером (sendPhoto + caption).

- Если в кастдеве найдутся новые формулировки болей — менять только §2 (welcome) и §4 (description). §3 (short) трогать только при смене позиционирования.
- Цифры (5 откликов, 10 карточек, 790 ₽, 7 минут) сверять с `docs/PRODUCT_FACTS.md` §3 и §5 перед публикацией.
