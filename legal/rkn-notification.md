# Уведомление о намерении осуществлять обработку персональных данных

Заполненная форма по Приложению № 1 к приказу Роскомнадзора от 28.10.2022 № 180 «Об утверждении форм уведомлений об обработке (намерении осуществлять обработку) персональных данных, об изменении сведений, содержащихся в уведомлении об обработке (намерении осуществлять обработку) персональных данных, о прекращении обработки персональных данных» (действующая редакция на 2026 год).

Документ предназначен для подачи через личный кабинет оператора на портале персональных данных Роскомнадзора (pd.rkn.gov.ru) с авторизацией через ЕСИА. Поля, отмеченные «Требует ручного ввода в личном кабинете», заполняются непосредственно в веб-форме (выпадающие списки, чекбоксы, повторяющиеся блоки). Поля «Не применимо» в форме явно проставляются «не осуществляется» / «отсутствует» / прочерком, в зависимости от структуры конкретного блока.

Уведомление о трансграничной передаче персональных данных оформляется отдельным документом по форме, размещённой по адресу pd.rkn.gov.ru/cross-border-transmission/form2/. Соответствующие сведения вынесены в раздел «Приложение. Уведомление о трансграничной передаче ПД» в конце настоящего файла.
